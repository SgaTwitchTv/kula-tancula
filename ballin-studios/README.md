# SWAY Studio

Animowany wariant: `/motion/`. Przezroczysty logotyp: `public/branding/sway-marker-transparent.png`. Interaktywny drugi outfit i większy opis Julii: `src/motion.ts`, `src/outfit.css`. Szczegóły i prompty: `LOGO-OUTFIT-PROMPTS.md`.

Responsywne demo szkoły tańca w TypeScript i Vite. Czerń, turkus z próbki, białe i szare dodatki. Branding: turkusowy markerowy logotyp SWAY STUDIO.

## Uruchomienie

`npm install`, następnie `npm run dev`. Produkcja: `npm run build` i `npm run preview`.

## Zakres

Strona główna, oferta koncepcyjna, filtrowany przykładowy grafik, FAQ i demonstracyjny formularz w oknie dialogowym. Formularz niczego nie wysyła ani nie zapisuje. Nazwa marki i imię założycielki pochodzą z briefu. Oferta, dni, godziny i teksty są propozycjami. Przed uruchomieniem należy uzupełnić lokalizację, ceny, prawdziwe zapisy i dane firmy.

Logo markerowe: `public/branding/sway-marker.png`, prezentowane w `src/main.ts`. Fotografie bazowe pochodzą z egurrola.com; postacie i stroje zmodyfikowano AI. Użytkownik potwierdził zgodę na przeróbki i publikację. Są to wizualizacje. Szczegóły: PHOTO-SOURCES.md. Nie przedstawiają kadry ani lokalu SWAY Studio. Galeria ma filtry i podgląd zdjęć. Lista źródeł: PHOTO-SOURCES.md.
