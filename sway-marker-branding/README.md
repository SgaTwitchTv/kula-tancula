# SWAY Studio — street marker

Nowa koncepcja znaku słownego bez osobnego symbolu S ani tancerza. Oryginalne liternictwo inspirowane ogólnym stylem markera z referencji użytkownika. Dominujący napis SWAY i mniejsze STUDIO. Kolor docelowy #2BD1EB. PNG na czarnym tle, wygenerowany wbudowanym Imagegen. Materiał koncepcyjny, nie plik wektorowy. Próby transparentne v1 i v2 mają niepożądaną poświatę i nie są finalnymi plikami użytkowymi.

Plik końcowy: sway-studio-marker.png. Podgląd na czerni: index.html. Poprzednie koncepcje pozostają zachowane w osobnych folderach.
